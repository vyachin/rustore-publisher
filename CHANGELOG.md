# История изменений

## [Unreleased]

## [0.0.4] — 2026-11-10

### Добавлено

- `publish` загружает необязательную иконку `ru-RU/images/icon.png` или
  `icon.jpg` из `--metadata-dir`. Проверяются PNG/JPEG, ровно 512×512 и размер
  до 3 МБ; после загрузки `iconUid` и `iconUrl` сверяются в подробностях
  версии. Остальные изображения по-прежнему попадают в `METADATA_IGNORED`.

### Изменено

- Вход действия `credentials-json-base64` переименован в `credentials-base64`
  для единообразия с `google-play-publisher`. Алиас не сохраняется: workflows,
  которые использовали старое имя, нужно обновить.

## [0.0.3] — 2026-11-10

### Добавлено

- `publish` читает из `--metadata-dir` необязательные `ru-RU/title.txt`,
  `ru-RU/short_description.txt` и `ru-RU/full_description.txt` и передаёт
  `appName`, `shortDescription` и `fullDescription` при создании черновика.
  Отсутствие файла наследует поле из активной версии; пустой файл, неверный
  UTF-8, лишняя строка или превышение лимита дают `INVALID_METADATA` (код 2)
  до обращения к API.
- Dependabot обновляет Go-модули и GitHub Actions раз в неделю; включены
  Dependabot alerts и security updates.

### Изменено

- `METADATA_IGNORED` больше не перечисляет название и описания: они
  публикуются. Изображения, другие локали и служебные файлы по-прежнему
  попадают в предупреждение.

## [0.0.2] — 2026-11-09

### Изменено

- `--metadata-dir` принимает каталог с раскладкой карточки другого магазина:
  публикуется только `ru-RU/changelogs/<код версии>.txt`, а остальные элементы
  каталога перечисляются в предупреждении `METADATA_IGNORED`. Отсутствие файла
  версии, пустой текст, неверная кодировка и превышение 5000 символов остаются
  ошибкой до обращения к API.

## [0.0.1] — 2026-11-09

### Добавлено

- CLI `rustore-publisher` 0.0.1: команды `publish`, `status`, `doctor`, `version`
  и `completion`.
- Авторизация RuStore по ключу RSA: подпись `keyId+timestamp`, кэш JWE-токена
  с обновлением за 60 секунд.
- Потоковая загрузка AAB, ожидание обработки и отправка на модерацию
  с `priorityUpdate=0`.
- Режимы публикации `manual` и `instantly`, `--dry-run`, `--if-exists=fail|skip`.
- Список изменений `metadata/ru-RU/changelogs/<код версии>.txt` и контакты
  разработчика `metadata/developer-contacts.json` или `--contacts-file`.
- Машинный JSON-результат с закрытыми перечислениями, коды завершения 0–8 и 130.
- Составные действия `setup` и публикации, архивы GoReleaser для Linux, macOS
  и Windows на amd64 и arm64.
- Документация формата `developer-contacts.json` с примерами и правилами.

### Исправлено

- Официальные сертификаты Минцифры встроены в бинарный файл через `go:embed`;
  домен `https://public-api-m.rustore.ru` используется по умолчанию и не требует
  `SSL_CERT_FILE`.
- Ошибка недоверенного TLS-сертификата сопровождается подсказкой про домены.

### Изменено

- Режим `instantly` публикует без дополнительного подтверждения; флаг подтверждения удалён.

### Ограничения

- Публикация в режиме `manual` после одобрения модерации выполняется в консоли RuStore.
- Частичный охват и метаданные карточки не поддерживаются.
- Ошибки `AAB_SIGNING_REQUIRED` и `PERMISSION_DECLARATION_REQUIRED` требуют
  проверенных ответов API и пока классифицируются общей категорией.
