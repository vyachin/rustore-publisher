# История изменений

## [Unreleased]

### Добавлено

- CLI `rustore-publisher` 0.0.1: команды `publish`, `status`, `doctor`, `version`
  и `completion`.
- Авторизация RuStore по ключу RSA: подпись `keyId+timestamp`, кэш JWE-токена
  с обновлением за 60 секунд.
- Потоковая загрузка AAB, ожидание обработки и отправка на модерацию
  с `priorityUpdate=0`.
- Режимы публикации `manual` и `instantly`, `--dry-run`, `--if-exists=fail|skip`.
- Список изменений `metadata/ru-RU/changelogs/<код версии>.txt` и контакты
  разработчика `metadata/developer-contacts.json` или `--contacts-file`.
- Машинный JSON-результат с закрытыми перечислениями, коды завершения 0–8 и 130.
- Составные действия `setup` и публикации, архивы GoReleaser для Linux, macOS
  и Windows на amd64 и arm64.

### Исправлено

- Официальные сертификаты Минцифры встроены в бинарный файл через `go:embed`;
  домен `https://public-api-m.rustore.ru` используется по умолчанию и не требует
  `SSL_CERT_FILE`. Старый домен доступен через `--api-url`.
- Ошибка недоверенного TLS-сертификата сопровождается подсказкой про домены.

### Ограничения

- Публикация после одобрения модерации выполняется в консоли RuStore.
- Отложенная публикация, частичный охват и метаданные карточки не поддерживаются.
- Ошибки `AAB_SIGNING_REQUIRED` и `PERMISSION_DECLARATION_REQUIRED` требуют
  проверенных ответов API и пока классифицируются общей категорией.
