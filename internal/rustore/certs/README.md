# Сертификаты Минцифры

Каталог содержит корневой и промежуточный сертификаты, официально
опубликованные для доступа к обновлённым доменам RuStore API. Они встроены
в бинарный файл через `go:embed` и добавляются к системному пулу доверия
только в HTTP-клиенте RuStore.

Источник: портал Госуслуг, ссылки из инструкции RuStore
«Подготовка сервера для работы с обновлёнными доменами RuStore API»:

- https://gu-st.ru/content/lending/russian_trusted_root_ca_pem.crt
- https://gu-st.ru/content/lending/russian_trusted_sub_ca_pem.crt

Сервер `public-api-m.rustore.ru` сейчас присылает промежуточный сертификат
с тем же именем, но выпущенный в 2024 году; он проверяется встроенным корнем.
Корневой сертификат — единственный якорь доверия, промежуточный добавлен
согласно официальной инструкции.

Доверие ограничено нашим API-клиентом: HTTP-редиректы запрещены, поэтому
встроенный CA не применяется к другим хостам.
