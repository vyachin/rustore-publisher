# Правила проекта

Эти правила действуют для всего репозитория.

## Язык документации

- Вся документация проекта пишется на русском языке: README.md, TODO.md,
  CHANGELOG.md, AGENTS.md, документы в docs/, архитектурные решения и пояснения
  в примерах команд и конфигураций.
- При добавлении или изменении документации используйте русский язык.
- Справка CLI, описания флагов и собственные сообщения CLI для пользователя —
  на русском. Сообщения внешнего API можно сохранять в исходном виде, добавляя
  пояснение по-русски.
- Названия команд, флаги, пути, идентификаторы, поля API и форматы данных
  сохраняйте в исходном виде; не переводите машинно обрабатываемые значения.

## Объём и устройство приложения

- Набор команд: doctor, status, version, completion и publish.
- Начальная версия приложения — `0.0.1`; тег первого выпуска — `v0.0.1`.
- План реализации и чек-лист находятся в TODO.md; подробный контракт —
  в docs/design.md. Не дублируйте правила в обоих файлах. При изменении поведения
  обновляйте контракт, при завершении задач — чек-лист.
- Используйте стек и подход google-play-publisher: Go, Cobra, один бинарный файл
  и GitHub Actions на основе CLI.
- Пишите понятный, легко читаемый код. Предпочитайте стандартную библиотеку,
  конкретные структуры и прямые вызовы; добавляйте абстракции только при
  практической необходимости.
