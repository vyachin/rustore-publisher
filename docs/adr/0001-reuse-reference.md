# ADR-0001. Переиспользование кода референса google-play-publisher

- Статус: принято
- Дата: 2026-11-09

## Контекст

Рядом с репозиторием находится собственный проект автора
`../google-play-publisher` — CLI на Go/Cobra для публикации AAB в Google Play
с разбором AAB, тестами, GoReleaser и составными GitHub Actions. В нём нет файла
лицензии, поэтому по умолчанию код нельзя копировать и распространять.

Ранее [TODO.md](../../TODO.md) запрещал копирование и требовал писать разбор AAB,
тесты и скрипты заново. Это удорожало 0.0.1 и повышало риск ошибок в разборе
`Resources.proto` и в публикации артефактов.

## Решение

Автор подтвердил, что оба репозитория принадлежат ему, и разрешил переиспользование
кода референса. Переносятся только части, не зависящие от Google Play:

- `internal/artifact` — разбор AAB, проверки манифеста, SHA-256;
- каркас CLI: `version`, `completion`, коды завершения, вывод JSON;
- тестовые помощники на `httptest`;
- `Makefile`, `.golangci.yml`, `.goreleaser.yaml`, CI-workflow;
- `setup/`, корневой `action.yml`, `scripts/`.

Не переносятся: клиент Google API, OAuth/ADC, треки, статусы, метаданные карточки,
`service_account.json`, собранные артефакты и любые учётные данные.

## Последствия

- В оба репозитория добавляется лицензия; перенесённые файлы сохраняют совместимую
  лицензию и упоминание источника.
- Перенос фиксируется в CHANGELOG и в сообщении коммита.
- Схема манифеста AAB сверяется с AOSP
  [Resources.proto](https://android.googlesource.com/platform/frameworks/base/+/refs/heads/main/tools/aapt2/Resources.proto)
  (Apache-2.0); при копировании фрагментов схемы добавляется NOTICE.
- Play-специфичное поведение (треки, статусы, `--track`) не переносится, даже если
  код выглядит нейтрально.
